## Unchecked risks

- **Audit-baseline drift anchor is missing.** Without the claimed comment
  trail of per-category formalization scores at the head of `non-functional.md`,
  there is no baseline against which a future Codex audit can measure progress.
  The first finding under "Findings" elevates this to `minor`; if the team
  treats baseline preservation as an ADR-0007 deliverable rather than a docs
  nicety, it should be re-classified to `major`.
- **`NFR-COST-1` deferral indefiniteness.** The deferral rationale points to
  "production-deployment phase" without naming a Task or trigger PR. There is
  no scheduled re-evaluation; the row could remain `TBD` indefinitely.
  Out-of-scope to fix in #79 but flagged here so the next NFR audit catches
  it.
- **No spec-level review of the NFR-PERF / NFR-SCALE thresholds against the
  actual CI runner profile.** The verifier did not run `pytest-benchmark`
  against the proposed thresholds (≥ 0.5 fold/s, ≤ 5 s median cycle, ≤ 2 s
  for `list_all_market_points` at 1 M points). Whether these are realistic
  on GitHub-hosted runners is for Task #89 to validate; until then the
  thresholds are aspirational. This is the explicit scope of `partial`
  status, not a bug.
- **Verifier ran in a single sandbox (macOS, Python 3.13 via uv).** The CI
  matrix (Linux × Python 3.12) was not exercised here; only the local gates.
  ADR-0027 / ADR-0007 do not require independent CI re-execution by the
  verifier, but the matrix-level NFR-PORT-1 enforcement claim is therefore
  unverified in this report.
- **Cross-family verification not performed.** Per ADR-027 v0.1.0, paper-scope
  PRs accept intra-family review; this report is intra-family (Claude
  orchestrator + Claude verifier). A live-broker (P4+) PR would require
  cross-family + human gate; not applicable here.
